# 🎮 Memory Card Matching Game

> A delightful interactive memory card game built with modern web technologies and smooth animations

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit-blue?style=for-the-badge)](https://main-projects-liart.vercel.app/)

---

## ✨ Features

### 🎯 Interactive Gameplay
Flip cards to find matching pairs with beautifully smooth animations and fully responsive design that works seamlessly across all devices.

### 🔄 Dynamic State Management
Leverages React hooks to intelligently track flipped cards, matched pairs, and game progress in real-time, providing a seamless player experience.

### 🎲 Shuffle & Replay System
Randomizes card positions for each new game and includes convenient restart functionality, ensuring endless replayability and fresh challenges every round.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or pnpm package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Rohit-Sharma3843/Main-Projects.git

# Navigate to the memory project directory
cd Main-Projects/memory

# Install dependencies
npm install
# or
pnpm install
```

### Running Locally

```bash
# Start the development server
npm run dev
# or
pnpm dev
```

The game will be available at `http://localhost:3000`

## 🎮 How to Play

1. **Flip Cards** - Click or tap on any card to flip it over
2. **Find Matches** - Try to remember card positions and find matching pairs
3. **Complete the Game** - Match all pairs to win
4. **Restart Anytime** - Use the restart button to shuffle and play again
